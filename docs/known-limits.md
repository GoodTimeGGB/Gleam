# 已知限制与刻意不做

> 「不做什么」的**唯一公开入口**：读到这里，就不会反复提出同样的建议。
> 每条一句理由。内部长文设计稿与对照清单若存在于维护者本机，不入库；**活口径以本文件为准**。
> 字数预算由 `scripts/check-doc-budget.py` 判并**告警**，不做门禁。

## 三个检验问题的答案

1. **知识外置了吗？** 负知识（限制 / 刻意不做）在这里；贡献与开发入口见 `CONTRIBUTING.md`。
2. **正确入口明确吗？** 问「为什么不是那样」看这里；改代码与提 PR 看 `CONTRIBUTING.md` 与组织级规范。
3. **错误何时被发现？** `scripts/verify.sh` 六层，任一层 exit non-zero 即拦住。

## 一、已知限制（现状如此，不是 bug）

| 限制 | 为什么这样 |
| :--- | :--- |
| 无容器 / seccomp 沙箱 | 「本地优先桌面」是产品前提；权限靠门控与审批 |
| 记忆检索是 FNV 词法哈希，非语义向量 | 零第三方依赖；「自己的笔记」规模下够用 |
| `trace_id` 不含时间戳 | 同输入同模型则 ID 相同，聚类才看得见「反复出现」 |
| `.csv` 不做结构校验 | 列数不齐也可能是合法数据 |
| 重规划摘要不贴输出正文 | 避免易变大块文本灌进重规划上下文 |
| 记忆四类冲突的完整版未做 | 单机场景下层级 / 来源冲突不成立 |
| 规划屡败回落直聊的任务留在指标分母 | 是一次失败交付；摘出去就是改比率 |
| 场景模板的 tools 是提示不是白名单 | 只决定哪些 schema 强制附上，拦不住别的工具 |
| max_concurrency 只管单任务 | 每次执行各建一个信号量，N 个任务并发就是 N×8 |
| `tool-output/` 是缓存不是归档 | 按任务数裁剪；提示语里已写明是临时文件 |
| 工具直调（`/api/tools/call`）不快照 | 无任务身份，快照无处归属 |
| `/api/conversation/reset` 单数、余下复数 | 历史命名；改要两侧同动，收益只有好看 |
| 反思只看每步 300 字输出 | 上下文经济；产物另有确定性核对兜底 |
| shell.exec 不杀进程树（只杀直接子进程） | 孤儿孙进程会残留；输出不完整会显式标记 |
| Go 工具链偶发读不到 std 或极慢 | 与代码无关，重跑即可；判据在 gonoise.sh |
| 进程创建 1.5~2.7 秒/次；mktemp 形态不稳 | 脚本因此分钟级；mktemp 须过 cygpath |
| doctor 的状态段只报位置与体量 | 是地图不是校验：不验完整性，也不判合格 |
| 二进制未做代码签名与 Apple 公证 | 无付费开发者账号与发布渠道；放行步骤写在 README |
| 更新包不校验签名，只核对来源域名与字节数 | 同上：没有签名密钥可比对；真要防中间人得先有发布签名 |
| Go 工具链安装的校验和是尽力而为 | 官方 sha256 清单拉不到（断网 / 被墙）时只核对来源域名，响应里会标 `verified: false` |
| 出网对账只认门控的字面量落点 | 扫不出自建的 http.Client；§4.6.34 |
| 候补目标只数本机留着的归档 | tasks/ 会裁剪；看不见≠没发生；§4.6.35 |

## 二、刻意不做（提过，明确否掉）

| 不做 | 理由 |
| :--- | :--- |
| 插件化架构（含改自己） | 扩展点已有四处；维护成本会吃掉可读性收益 |
| 多 Agent 协作 / Graph Engineering | 单任务下上下文隔离不是瓶颈，汇总三坑难处理 |
| 完整断点续跑 / 状态机恢复 | 成本最高、收益未验证；单机下人工重提即可 |
| 执行权租约 + 迟到结果失效 | 单进程单执行器，不存在一条命令交给两个进程 |
| Session / 事件续读 / 断线重连 | 无客户端-服务端分离；桌面端就是唯一前端 |
| LLM-as-Judge 偏差控制 | 评测是行为型、客观可判定，不需要 judge |
| 按概率裁剪历史 | 会破坏 compaction 并重写 Prompt Cache |
| 验收标准库（按意图复用标准） | 省不下调用；拿错配的尺子量比重新定更糟 |
| 字数预算做成硬门禁 | 长度只是「找得快」的代理指标，不是目的 |
| 灰度发布 / 回滚条件 | 桌面单机，无灰度概念 |
| 沙箱按需创建/预热/保留期、FUSE 按需加载 | 本地无容器编排，也无云端资源层 |
| 训练指纹与 checkpoint 复现 | 不训练模型；可复现落在 `replay` + `trace_id` |
| 高频游戏 / NPC 决策 | 场景不成立 |
| 把技能 manifest 注入提示词 | 反方向：已用「技能不进提示词」解决 |
| 反馈外发截图字节 | 只发文件名/类型/字节数；截到什么事先决定不了 |
| 反馈投递失败自动重试 | 只做手动重投；静默重投等于替用户决定要不要送 |
| 恢复「失败步骤之后的跳过链」 | `--from` 忠实还原当时前提；改走法用分叉 |
| `gleam rules` 装配运行时 | 规则表是编译期常量；排障时往往正是配置坏了 |
| 向量语义检索（知识引擎） | 与 Gleam 无关（非 RAG 系统） |
| 还原走写前快照，不走 git | 快照回答的是「本任务之前」，git 回答的是「上次提交之前」，不是同一个问题 |
| `git push` 是出网，但台账看不见 | 出网对账只认门控的字面量落点；推送由我们的 git 工具跑，不是 http.Client |
| Worktrees 尚未接入执行 | 每个任务在自己的 worktree 里跑会改文件边界与还原口径，单独立项 |
| 自动更新（后台静默下载并替换） | 只做「检查 + 用户点了才下载替换」；静默替换等于替用户决定装什么 |
| 连接器目录 / SaaS 一键安装 | 无分发能力；§4.6.34 |
| 外部信号触发的主动提议 | 本机无信号源，且要可复现；§4.6.35 |
| 候补目标自己跑起来 | 执行仍归那一下回车；§4.6.35 |
| 工作记忆用 SQLite | 内嵌要引外部包；`tasks/*.json` 担同等职责 |
