# 已知限制与刻意不做

> 「不做什么」的**唯一入口**：agent 读到这里，就不会反复提出同样的建议。
> 每条只给一句理由；多段论证在设计文档 §4.6.x 与根目录四份对照清单（后者是报告原文，本文件是活口径）。
> 字数预算由 `scripts/check-doc-budget.py` 判并**告警**（不做门禁的理由见设计文档 §4.6.23）。

## 三个检验问题的答案

1. **知识外置了吗？** 铁律在 `AGENTS.md`，限制与负知识在这里，理由在设计文档。
2. **正确入口明确吗？** 改代码看 `AGENTS.md` 布局表；问「为什么不是那样」看这里。
3. **错误何时被发现？** `scripts/verify.sh` 六层，任一层 exit non-zero 即拦住。

## 一、已知限制（现状如此，不是 bug）

| 限制 | 为什么这样 |
| :--- | :--- |
| 无容器 / seccomp 沙箱 | 「本地优先桌面 Agent」是产品前提；权限靠门控与审批 |
| 记忆检索是 FNV 词法哈希，非语义向量 | 零第三方依赖；「用户自己的笔记」规模下够用 |
| `trace_id` 不含时间戳 | 同输入同模型 ID 相同，失败聚类才看得见「反复出现」 |
| `.csv` 不做结构校验 | 列数不齐也可能是合法数据 |
| 重规划摘要不贴输出正文 | 避免易变的大块文本灌进重规划上下文 |
| 记忆四类冲突的完整版未做 | 单机场景下层级 / 来源冲突不成立 |
| 规划屡败回落直聊的任务留在指标分母 | 它确实是一次失败交付，摘出去就是改比率 |
| 场景模板的 tools 是提示不是白名单 | 只决定哪些 schema 强制附上，拦不住别的工具 |
| max_concurrency 只管单任务，不是全局 | 每次执行各建一个信号量，N 个任务并发就是 N×8 |
| `tool-output/` 是缓存不是归档 | 按任务数裁剪；提示语里已写明是临时文件 |
| 工具直调（`/api/tools/call`）不快照 | 无任务身份，快照无处归属 |
| `/api/conversation/reset` 单数、余下复数 | 历史命名；改要两侧同动，收益只有好看 |
| 反思只看每步 300 字输出 | 上下文经济；产物另有确定性核对兜底 |
| shell.exec 不杀进程树（只杀直接子进程） | 孤儿孙进程会残留；输出不完整会显式标记 |
| 单文件二进制约 7.5MB、零第三方依赖 | 有些能力因此刻意自研，而不是引入库 |
| Go 工具链偶发读不到标准库 | 与代码无关；判据只在 scripts/lib/gonoise.sh |
| 本机进程创建是秒级（1.5~2.7 秒/次） | 多进程 shell 脚本因此是分钟级；探针就是分钟级 |
| Go 工具链偶发进入极慢状态 | 单包 go vet 也会超 2 分钟；与代码无关，重跑或等一会 |
| mktemp 返回形态不稳定 | 可能是 /tmp/x 也可能是 C:\…\Temp/x；须过 cygpath |
| doctor 的状态段只报位置与体量 | 是地图不是校验：不验内容完整性，也不判合格 |
| 出网对账只认门控的字面量落点 | 闸门读源码，扫不出自己起的 http.Client；§4.6.34 |
| 候补目标只数本机留着的归档 | tasks/ 会裁剪；「看不见≠没发生」已写在页面上；§4.6.35 |

## 二、刻意不做（提过，明确否掉）

| 不做 | 理由 |
| :--- | :--- |
| 插件化架构（能力全插件化，含改自己） | 扩展点已有四处，维护成本会吃掉可读性收益 |
| 多 Agent 协作 / Graph Engineering | 单任务下上下文隔离不是瓶颈，汇总三坑难处理 |
| 完整断点续跑 / 状态机恢复 | 成本最高、收益未验证；单机下人工重提即可 |
| 执行权租约 + 迟到结果失效 | 单进程单执行器，不存在一条命令交给两个进程 |
| Session / 事件续读 / 断线重连 | 没有客户端-服务端分离，桌面端就是唯一前端 |
| LLM-as-Judge 偏差控制 | 评测是行为型、客观可判定，不需要 judge |
| 按概率裁剪历史 | 会破坏 compaction 并重写 Prompt Cache |
| 验收标准库（按意图复用标准） | 省不下调用；拿错配的尺子量比重新定更糟 |
| `docs/adr/` 目录 | 理由在设计文档有据可查；等需要索引再建 |
| 字数预算做成硬门禁 | 长度只是「找得快」的代理指标，不是目的 |
| 灰度发布 / 回滚条件 | 桌面单机，无灰度概念 |
| 沙箱按需创建 / 预热 / 保留期扫描 | 本地无容器编排；保留期就是文件还在不在 |
| FUSE 按需加载云端资源 | 无云端资源层 |
| 训练指纹与 checkpoint 复现 | 不训练模型；可复现已落在 `replay` + `trace_id` |
| 高频游戏 / NPC 决策 | 场景不成立 |
| 把技能 manifest 注入提示词 | 反方向：已用「技能不进提示词」解决 |
| 反馈外发截图字节 | 只发文件名/类型/字节数；截到什么不由我们事先决定 |
| 反馈投递失败自动重试 | 只做手动「重新投递」；静默重投等于替用户决定要不要送 |
| 恢复「失败步骤之后的跳过链」 | `--from` 忠实还原当时前提，想改走法用分叉 |
| `gleam rules` 装配运行时 | 规则表是编译期常量；排障时往往正是配置坏了 |
| 向量语义检索（知识引擎） | 与 Gleam 无关（非 RAG 系统） |
| 还原：不接 git、不在还原前另存 | 要的是"本任务之前"；没有查看入口就是半截功能 |
| 联网检测版本更新 | 无更新源可查，凭空的 GET 就是出网；见设计文档 §4.6.33 |
| 连接器目录 / 第三方 SaaS 一键安装 | 无分发能力，抄来只得到一排「敬请期待」；§4.6.34 |
| 外部信号触发的主动提议 | 本机没这些信号的来源；接上要常驻监听，而它得可复现；§4.6.35 |
| 候补目标自己跑起来 | 会执行的卡把「我允许了什么」搬回后台；执行仍然是按回车那一刻；§4.6.35 |
| 工作记忆用 SQLite | 内嵌要引外部包，破零第三方依赖；`tasks/*.json` 担同等职责 |

## 三、还没到条件（不是不做）

| 项 | 等什么 |
| :--- | :--- |
| `docs/adr/`、Skills 运行时查询、防漂移检查 | 真有组合压力时（B12） |
| 判断分层 P4-1（结构化判断 + 置信度 + 级联） | 需 LLM 凭证做实测 |
| 图文生成（出图） | 三条线协议都只出文本；要新增图像出口与产物落盘 |
| 视觉输入（读图） | 消息只有 text 段，截屏工具存下的图送不进模型 |
